# Quiz Service

Сервис для проведения онлайн-квизов и викторин. Организаторы могут создавать квизы, настраивать вопросы и таймеры, запускать игровые сессии. Участники могут подключаться по коду, отвечать на вопросы и видеть результаты.

## Функциональные возможности

### Для организатора
- Регистрация и вход в систему
- Создание, редактирование и удаление квизов
- Добавление вопросов с вариантами ответов
- Настройка таймера на квиз или на отдельный вопрос
- Создание игровой сессии с уникальным кодом
- Просмотр результатов участников
- Статистика по вопросам (процент правильных ответов)

### Для участника
- Подключение к игре по коду (без регистрации)
- Синхронное прохождение квиза
- Отслеживание таймера
- Просмотр своих результатов

## Технологический стек

### Бэкенд
- **Django** — веб-фреймворк
- **Django REST Framework** — создание API
- **JWT** — аутентификация
- **PostgreSQL** — база данных
- **Redis** — кэширование и временные данные
- **Celery** — фоновые задачи

### Фронтенд
- **React 18** — UI библиотека
- **TypeScript** — типизация
- **Vite** — сборка проекта
- **Tailwind CSS** — стилизация
- **Zustand** — управление состоянием
- **React Router** — маршрутизация
- **Axios** — HTTP клиент

## Требования

- Python 3.10+
- Node.js 18+
- Docker и Docker Compose (опционально)
- PostgreSQL 14+
- Redis 7+

## Установка и запуск

### Вариант 1: Docker (рекомендуется)

```bash
# Клонировать репозиторий
git clone https://github.com/your-org/quiz-service.git
cd quiz-service

# Скопировать пример переменных окружения
cp .env.example .env

# Запустить все сервисы
docker-compose up -d

# Выполнить миграции
docker-compose exec backend python manage.py migrate

# Создать суперпользователя (опционально)
docker-compose exec backend python manage.py createsuperuser
