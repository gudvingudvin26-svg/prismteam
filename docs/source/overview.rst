Project overview
================

Проект состоит из двух Django-приложений:

* ``quiz`` — основная бизнес-логика квизов, пользователей, WebSocket,
  валидации и логирования.
* ``quiz_sessions`` — управление игровыми сессиями и ответами участников.

Основные возможности
--------------------

* регистрация и авторизация через JWT;
* создание и редактирование квизов;
* WebSocket-коммуникация в реальном времени;
* система игровых сессий;
* кастомные сериализаторы и валидаторы;
* JSON-логирование и middleware;
* репозитории и фабрики для бизнес-логики.

Архитектура проекта
-------------------

Проект построен по принципу разделения ответственности:

* ``models.py`` — модели базы данных;
* ``serializers.py`` — преобразование данных API;
* ``views.py`` — HTTP API и обработка запросов;
* ``consumers.py`` — WebSocket-логика;
* ``repositories.py`` — доступ к данным;
* ``validators.py`` — бизнес-валидация;
* ``middleware.py`` — промежуточная обработка запросов;
* ``logging_config.py`` — централизованное логирование.

Технологии
-----------

* Django
* Django REST Framework
* Django Channels
* Redis
* JWT Authentication
* WebSocket
